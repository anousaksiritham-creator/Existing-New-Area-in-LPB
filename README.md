# LPB Hotel — Existing building viewer

Interactive 3D / 2D viewer of the existing building (survey state), single offline HTML file: `index.html`.

- 3D model with materials, sun position, OSM context; edges shown by default.
- CAD sheets EX-01 / EX-02 from the survey DWG; elevations, sections, roof and site plans generated from the 3D model (not CAD, not site-verified).
- Room, door/window and column schedules; source tag on every element (DWG / estimated / assumed).

Map data © OpenStreetMap contributors (ODbL). Terrain: SRTM 30 m via OpenTopoData.
