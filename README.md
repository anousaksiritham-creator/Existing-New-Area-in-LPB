# LPB Hotel — Existing building + proposal viewer

Interactive 3D / 2D viewer of the existing building (survey state) and the proposed conversion into a 4-room hotel with a tour office, single offline HTML file: `index.html`.

- **Existing:** 3D model with materials, sun position, OSM context; edges shown by default. CAD sheets EX-01 / EX-02 from the survey DWG; elevations, sections, roof and site plans generated from the 3D model (not CAD, not site-verified). Room, door/window and column schedules; source tag on every element (DWG / estimated / assumed).
- **Proposed (options A and B):** F2 = 4 en-suite guest rooms, GF = tour office with a shared reception counter. New partitions, furniture and the cream / sage exterior palette in 3D; plan sheets PR-01 and PR-02A / PR-02B at 1:100; areas and minimum-size checks per room. Open directly with `#proposed-A` or `#proposed-B`.
- The proposal is a concept, not a construction drawing. Exterior changes are pending approval by the landlord and the World Heritage office.

Map data © OpenStreetMap contributors (ODbL). Terrain: SRTM 30 m via OpenTopoData.
